
Install program:
-------------------------------------------
sudo apt install conky-all
sudo apt-get install mesa-utils


Copy config files:
-------------------------------------------
cp drawGraphics.lua /etc/conky/
cp conky.conf /etc/conky/
(Copy from hostname folder... if they are updated.... should aim for single files, not host specific ones)



Enable autostart:
-------------------------------------------
cp conky.desktop  ~/.config/autostart/
